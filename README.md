# KT tools

Букмарклет для админки Кейтаро: замена pixel / token / домена в кампаниях по куску нейминга
и дубли кампании по ID под список кабинетов. Вкладка «Аналитика» показывает утренний анализ
из Google Таблицы (код таблицы — `kt_analytics_sheet.gs`, установка — в шапке файла).

**Установка:** открыть https://artemshchitov.github.io/kt-tools/ и перетащить кнопку на панель закладок.

API-ключ Кейтаро вводится в самой панели и хранится только в браузере (localStorage), в репозиторий не попадает.

## Разработка

Исходник — `kt_pixel_bookmarklet.js`. После правок:

```
python build.py
```

— пересобирает `index.html`, затем закоммитить и запушить. Коллегам — удалить старую закладку и перетащить заново.

## Мониторинг креативов на S3

`creo_monitor_sheet.gs` — Apps Script для отдельной Google Таблицы: видео с твоим именем из `CreoAntonTeam/`
с начала месяца, гео по неймингу, статус «готов к заливу», если в Кейтаро (sub_id_3) по креативу не было расхода.
Установка — в шапке файла.
