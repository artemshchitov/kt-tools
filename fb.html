FB: снятие ложных отклонов

Букмарклет: по списку кабинетов находит отклонённые объявления под активными кампаниями, подставляет белый заголовок (язык — по названию кампании) и переотправляет на ремодерацию.

Ещё инструмент: KT pixel / token / домен.

FB отклоны

Установка
  1. Показать панель закладок: Ctrl+Shift+B.
  2. Перетащить синюю кнопку выше на панель закладок.
Обновление: удалить старую закладку и перетащить заново.
Работа
  1. Открыть business.facebook.com под нужным профилем и нажать закладку — справа появится панель.
  2. Один раз вписать FB-токен системного юзера (с правом ads_management). Хранится только в браузере.
  3. Вписать кабинеты — ID по одному в строке.
  4. Галка «менять заголовок на белый» — язык берётся по префиксу гео в названии кампании (au_… → EN, de_… → DE и т.д.). Снять галку — просто переотправка без смены текста.
  5. «Проверить» → виден список отклонённых под активными кампаниями → «Применить».
  6. После отправки через ~10 с показываются статусы: ACTIVE — снято, IN_PROCESS — в ревью, DISAPPROVED — жёсткий отклон (переотправкой не лечится).
Работает только с активными кампаниями; отклоны в отключённых пропускаются. Объявление не дублируется — пересобирается его же креатив (ad ID сохраняется).
