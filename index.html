KT pixel / token / домен

Букмарклет для админки Кейтаро: находит кампании по куску нейминга и меняет в них пиксель, токен и домен.

KT pixel/token

Установка
  1. Показать панель закладок: Ctrl+Shift+B.
  2. Перетащить синюю кнопку выше на панель закладок.
Обновление: удалить старую закладку и перетащить заново.
Работа
  1. Открыть админку Кейтаро и нажать закладку — справа появится панель.
  2. Один раз вписать API-ключ Кейтаро (Настройки → API). Он хранится только в твоём браузере.
  3. Вкладка Pixel / Token: pixel и token вписываются в отдельные поля и встают во все кампании из списка строк. Пустое поле — не меняется.
  4. Вкладка Домены — независимо от пикселя: слева строки, справа домены, поровну. Домен №N → кампании строки №N. Счётчик под полями показывает, сошлось ли.
  5. Вкладка Дубли: ID кампании-образца и нейминги кабинетов по одному в строке. Сколько строк — столько дублей. Дубль — полная копия образца (потоки, домен, параметры), в названии кабинет образца заменён неймингом строки. Кабинет образца находится сам (длинное число в названии) или вписывается вручную.
  6. Вкладка Аналитика: при открытии панели подтягивает утренний анализ из Google Таблицы (гео: масштабировать / сокращать, минусовые кампании: заменить креатив / выключить). Один раз вписать ссылку и ключ из меню таблицы «KT аналитика → Ссылка для букмарклета». Кнопка «→ в Дубли» переносит образец для масштаба во вкладку «Дубли».
  7. Строки — куски нейминга (кабинеты), по одному в строке.
  8. «Проверить» → посмотреть план → «Применить». После записи каждая кампания перечитывается и сверяется.
